# Campus Food Delivery App - Nibble

A simple web application for campus food delivery built with Node.js and Express.

## Features

- User login/registration
- Menu display with categories
- Shopping cart functionality
- Order placement
- Admin panel to manage orders

## Installation

1. Clone or download the project.
2. Navigate to the project directory.
3. Install dependencies: `npm install`
4. Start the server: `npm start`
5. Open http://localhost:3000 in your browser.

## Usage

1. Login with your name and email.
2. Browse the menu and add items to cart.
3. Checkout to place the order.
4. For admin access, login with email `admin@campus.com`.

## Technologies Used

- Node.js
- Express.js
- HTML/CSS/JavaScript

## Project Structure

- `server.js`: Backend server with API endpoints
- `public/index.html`: Main HTML page
- `public/script.js`: Frontend JavaScript
- `public/style.css`: Stylesheet
